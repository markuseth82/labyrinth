# Labyrinth

A walled city at the centre of an endless maze. Something in the maze hunts you.

Play: open the GitHub Pages link for this repository in Chrome or Edge.

WASD move, mouse look (click the view first), Shift sprint, F fly, 1 maze, 2 city, 3 wall top, 4 overview, M sound. Touch: left thumb moves, right thumb looks.

Built with three.js r160 (MIT).
